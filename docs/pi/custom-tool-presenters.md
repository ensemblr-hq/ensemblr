# Pi custom tool presenters

Ensemblr renders the following Pi extension tool calls with dedicated timeline titles, previews, bodies, and glyphs. Dispatch is centralized in [`src/renderer/lib/agent-timeline/tool-presenters.ts`](../../src/renderer/lib/agent-timeline/tool-presenters.ts); each extension owns its mapping below.

| Extension | Tools | Presenter source | Tests |
| --- | --- | --- | --- |

| Context7 | `context7_resolve_library_id`, `context7_get_library_docs`, `context7_get_cached_doc_raw` | [`src/renderer/lib/agent-timeline/context7-tool-presenters.ts`](../../src/renderer/lib/agent-timeline/context7-tool-presenters.ts) | [`tests/renderer/context7-tool-presentation.test.ts`](../../tests/renderer/context7-tool-presentation.test.ts) |
| context-mode | `ctx_execute`, `ctx_execute_file`, `ctx_batch_execute`, `ctx_fetch_and_index`, `ctx_index`, `ctx_search`, `ctx_doctor`, `ctx_insight`, `ctx_purge`, `ctx_stats`, `ctx_upgrade` | [`src/renderer/lib/agent-timeline/context-mode-tool-presenters.ts`](../../src/renderer/lib/agent-timeline/context-mode-tool-presenters.ts) | [`tests/renderer/context-mode-tool-presentation.test.ts`](../../tests/renderer/context-mode-tool-presentation.test.ts) |

| pi-background-tasks | `bg_run`, `bg_run_pi_attested`, `bg_status`, `bg_logs`, `bg_kill`, `bg_delegate`, `bg_result`, `fusion_reason`, `fusion_investigate`, `fusion_research`, `fusion_validate` | [`src/renderer/lib/agent-timeline/background-task-tool-presenters.ts`](../../src/renderer/lib/agent-timeline/background-task-tool-presenters.ts) | [`tests/renderer/extension-tool-presentation.test.ts`](../../tests/renderer/extension-tool-presentation.test.ts) |

`pi-web-access` custom tool-name overrides match only these default names. Add aliases to its presenter mapping when configuring alternate names.

`@dietrichgebert/ponytail` exposes commands, skills, and status, not tools; it needs no timeline tool presenter.
